## What I Do

- **Lead delivery** — scope, estimates, sprint planning, PR review on every commit, and release sign-off across several client projects at once.
- **Build production apps** — architecture, offline-first data, Firebase/Supabase backends, Django REST integrations, native platform modules when Flutter or RN can't reach.
- **Own the stores** — signing, provisioning, store compliance, metadata, screenshots and review rejections. Ship through Fastlane + GitHub Actions.
- **Run QA and release** — device testing on real hardware, performance audits, crash-free builds before anything reaches a client.
- **Client-facing** — technical point of contact: demos, change requests, scope control, post-launch support.
